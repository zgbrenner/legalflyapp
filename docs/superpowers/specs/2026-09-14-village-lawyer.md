# The Village Lawyer

The approved project replaces Legal Dreaming and the earlier classifier with a browser-local fictional village-law practice, inspired by Pieter Brueghel the Younger's Village Lawyer. No legacy reduced graph or API classifier is a fallback.

## Product
Office with eight authored petitions, structured editable facts, original-painting stage with selectable villagers, full-network consultation, explicitly artificial learned advice, editable teaching examples, persistent-by-export casebook, village reputation, local model/session import and export, cancellation, a neural activity inspection tab and a reproducible audit. Advice is not a judicial ruling. The charter is original game logic, not historical law or real legal advice. Entered prose is a case note, not secretly parsed by an LLM.

## Scientific contract
Use every classified neuron in official MaleCNS v1.0 and every published connection between those neurons at the source's minconf 0.5 cutoff. Preserve isolated classified neurons. Report excluded unclassified segment edges and source row counts. No top-k neurons, edge threshold, synthetic graph or hemibrain fallback. Synthetic small fixtures exist only in explicitly named unit tests. Every retained connection participates in the rate simulation. Engineered input and readout electrodes and a trained artificial readout are disclosed. No consciousness, biological memory, dopamine learning or legal comprehension claims. Validation reports measured failure as readily as success.

## Delivery
Static HTML/CSS/ES modules, dependency-free browser and Node runtime, Python Arrow preprocessing only at build time. Dedicated Web Worker. Chunked graph with independently SHA-256-checked payloads and source SHA-256 pins. No network calls carrying cases. No analytics, paid services, credentials or accounts. Raw data are cached outside Git; prepared static site is an Actions artifact. Full-data CI and desktop/mobile browser tests. Changes on codex/village-lawyer; original preserved in parent history; no automatic public deployment.

## Visual system
Actual public-domain painting rather than an AI imitation. Parchment (#f0ebde), ink (#282920), oxblood (#733c32), dark olive (#394134), fine rules, square-edged paper, oversized Georgia headings, restrained system sans UI. Museum image is downloaded and served locally, never hotlinked at runtime. Art credit points to MSK Ghent. Responsive office/detail split, not a marketing site or generic dashboard. Original fly line icon is a UI emblem, not a claim of anatomical fidelity. Activity is actual recorded state, schematic sampling explicitly labeled. Keyboard accessible navigation, visible focus, reduced motion, no continuous synthetic firing animation.

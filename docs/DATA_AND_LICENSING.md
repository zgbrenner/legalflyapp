# Data Sources & Licensing

LegalFly uses biological connectome topology as a **computational reservoir**.
This document records provenance, license terms, redistribution constraints, and
how the repository stays legally and practically usable as an open-source project.

> This is not legal advice. Verify current license texts before redistribution.

## Summary

| Resource | Role in LegalFly | License | Redistribution in repo | Commercial use | Demo default |
|---|---|---|---|---|---|
| Synthetic demo graph | Interactive demo + CI | MIT (project-generated) | Yes (small) | Yes | Fallback |
| FlyWire FAFB / whole-brain connectome | Optional research-scale reservoir | **CC BY-NC 4.0** | No (download separately) | **No** | No |
| Janelia hemibrain (neuPrint compact adjacency) | Preferred research reservoir | **CC BY 4.0** | No (download ~44MB; process locally) | Yes (with attribution) | **Preferred when built** |
| Synthetic sensitive-text benchmark | Task #1 dataset | MIT (project-generated) | Yes | Yes | Yes |
| `all-MiniLM-L6-v2` (optional encoder) | Text embeddings | Apache-2.0 (model card) | Not vendored; downloaded by user | See model card / training-data caveats | Hashing encoder used instead in demo |

## 1. Demo connectome (default)

**Source:** Generated by `research/graphs/build_demo_connectome.py`  
**Location:** `data/demo/connectome/`  
**License:** MIT, as part of this repository  
**Attribution:** LegalFly project  
**Redistribution:** Permitted  
**Commercial use:** Permitted under MIT  

The demo graph is a **small modular sparse network** (~512 nodes) with region labels.
It is **not** anatomical fly data and must not be described as FlyWire/hemibrain anatomy.

Node layouts are **abstract region clusters**, not Drosophila morphology.

## 2. FlyWire (optional research mode)

**Source:** [FlyWire](https://flywire.ai/) / [Codex](https://codex.flywire.ai/)  
**Public release license:** [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/)  
**Citation guidelines:** https://flywire.ai/guidelines  

### Findings (as of research performed for this project)

1. **Exact source:** FlyWire public release connectome data (e.g. FAFB snapshot / Codex downloads).
2. **License:** Creative Commons Attribution-NonCommercial 4.0 International (CC BY-NC 4.0).
3. **Attribution:** Required (credit FlyWire / contributors; cite relevant papers and guidelines; indicate modifications).
4. **Redistribution:** Allowed under CC BY-NC terms with attribution, but **not** committed to this repository because of size and to avoid accidental commercial packaging.
5. **Commercial use:** **Not permitted** under CC BY-NC.
6. **Practical handling:** Provide an importer script; store processed artifacts under ignored `data/raw/` and `data/processed/` paths.

**Implication for LegalFly:** FlyWire is excellent scientifically for whole-brain topology, but its NonCommercial clause makes it a poor default for a permissively licensed OSS monorepo that others may use commercially. Research users may still download it for non-commercial experiments.

## 3. Janelia hemibrain (preferred optional full connectome)

**Source:** FlyEM Hemibrain via [Janelia](https://www.janelia.org/project-team/flyem/hemibrain) / [neuPrint](https://neuprint.janelia.org/)  
**Dataset license:** Creative Commons Attribution 4.0 (CC BY 4.0) per Janelia project pages and community dataset indexes  
**Primary paper:** Xu, Scheffer, Plaza, et al., *A Connectome of the Adult Drosophila Central Brain*

### Findings

1. **Exact source:** Hemibrain EM reconstruction (~central brain fraction of *Drosophila melanogaster*).
2. **License:** CC BY 4.0 (dataset).
3. **Attribution:** Required; cite Xu et al. and identify dataset version (e.g. v1.2).
4. **Redistribution:** Permitted under CC BY with attribution; **not** vendored here due to multi-GB size.
5. **Commercial use:** Permitted under CC BY with attribution.
6. **Practical handling:** `scripts/import_hemibrain.py` documents download + conversion into LegalFly's sparse CSR format.

**Implication for LegalFly:** Prefer hemibrain for research-mode imports when a permissive open license is required.

## 4. Sensitive-information benchmark

All passages are **synthetic**. No real personal data is included.
Generator: `research/datasets/generate_sensitive_dataset.py`  
Outputs: `data/demo/sensitive/{train,validation,test}.jsonl`

## 5. Text encoder

- **Demo / default:** `HashingTextEncoder` (384-d feature hashing) — no external model download.
- **Optional research:** `sentence-transformers/all-MiniLM-L6-v2` (Apache-2.0 model card). Users should review training-data license discussions before commercial deployment.

## 6. Repository policy

- Do **not** commit multi-gigabyte connectomes.
- Do **not** silently download huge datasets in default `make install`.
- Demo mode must run after clone with only redistributable assets.
- Full connectome use is opt-in via documented scripts.
- Preserve attribution for any imported biological graph in processed metadata JSON.

## 7. How to enable research-scale graphs

```bash
# After reviewing licenses:
python scripts/import_hemibrain.py --help
python scripts/import_flywire.py --help
export LEGALFLY_DEMO_MODE=false
```

# Legal Fly Artwork

These three layered production assets were generated specifically for this project with OpenAI image generation on 2026-09-14. They do not redistribute museum photography or a scan of *The Village Lawyer*.

- `chamber.webp`: empty original Flemish office background plate.
- `desk.webp`: transparent desk and papers plate.
- `villagers.webp`: transparent five-character petitioner sprite plate.

The application keeps villagers, desk instruments, petitions, seals, fly, text, and controls as separate DOM layers so presentation motion remains independent from neural computation.

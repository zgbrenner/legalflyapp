# Legal Fly Artwork

These four layered production assets were generated specifically for this project with OpenAI image generation on 2026-09-14. They do not redistribute museum photography or a scan of *The Village Lawyer*.

- `chamber.webp`: empty original Flemish office background plate.
- `desk.webp`: transparent desk and papers plate.
- `villagers.webp`: transparent five-character petitioner sprite plate.
- `fly-counsel.webp`: transparent anatomically recognizable fruit-fly counsel with a restrained lawyer's neckband.

The application keeps villagers, desk instruments, petitions, seals, fly, text, and controls as separate DOM layers so presentation motion remains independent from neural computation. The small activity mark and the larger head overlay are driven by worker frames. Decorative grooming remains illustrative.
